# 🔴 Román Rojo: El Mensajero del Sabor

**Román Rojo: El Mensajero del Sabor** es una experiencia transmedia desarrollada para la asignatura **Electiva Transmedia, Medios y Tecnología** de la Universidad Militar Nueva Granada.

El proyecto presenta a **Román Rojo**, un repartidor legendario que recorre diferentes escenarios de Colombia llevando Kola Román y enfrentándose a obstáculos que representan el contraste entre la tradición y la modernidad.

La experiencia conecta una página web, un videojuego tipo runner 2D, contenido audiovisual, postales coleccionables y recuerdos de los usuarios.

## 🧭 ¿Cómo recorrer la página?

La página funciona como un sitio de una sola pantalla con diferentes secciones.

Desde el menú superior puedes acceder a:

### 🎮 Juego

Sección `#juego`

Aquí se encuentra la experiencia principal de **Román Rojo**, un videojuego runner/plataformas 2D.

El jugador acompaña a Román a través de distintos escenarios:

* Cartagena
* Barranquilla
* Pueblos ribereños
* Montaña

Durante el recorrido debe superar obstáculos y avanzar por la ruta de Román.

---

### 🖼️ Postales

Sección `#postales`

Aquí puedes consultar las **postales coleccionables** obtenidas durante la experiencia.

Las postales pueden aparecer inicialmente bloqueadas y se desbloquean al avanzar en el juego o ingresar desde determinados contenidos de la experiencia transmedia.

El progreso queda guardado localmente en el navegador.

---

### 💭 Memorias

Sección `#memorias`

Este espacio permite que los usuarios participen en el universo de Román Rojo dejando recuerdos relacionados con la familia, las tradiciones y las experiencias culturales.

Los recuerdos forman parte de la dimensión participativa del proyecto.

---

## 💾 ¿Se guarda mi progreso?

Sí.

El progreso de la experiencia se guarda de manera **local en el navegador**, por lo que no es necesario crear una cuenta ni iniciar sesión.

Esto permite conservar elementos como:

* Postales desbloqueadas.
* Progreso de los capítulos.
* Información relacionada con la experiencia del usuario.

⚠️ Si se borran los datos o el almacenamiento del navegador, el progreso local también puede eliminarse.

## ⚠️ Importante sobre Unity WebGL

El juego utiliza una versión WebGL de Unity.

Por esta razón, dependiendo de la configuración del navegador, abrir directamente `index.html` haciendo doble clic puede provocar que algunos archivos del juego no carguen correctamente.

Para probar el sitio localmente es recomendable utilizar un servidor local.

Por ejemplo, si tienes Python instalado:

```bash
python -m http.server 8000
```

Después abre en el navegador:

```text
http://localhost:8000
```

## 🎯 Objetivo del proyecto

**Román Rojo: El Mensajero del Sabor** busca representar la tradición de Kola Román y su relación con la cultura del Caribe colombiano a través de una narrativa participativa.

Román no funciona únicamente como repartidor dentro de la historia: representa un vínculo entre generaciones, comunidades y recuerdos alrededor de una tradición cultural.
